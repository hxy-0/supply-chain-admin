# 商品管理第一阶段

- 入口：管理员登录后访问 `/pms/products`，菜单为“商品管理 / 商品列表”。
- 支持名称/编码、分类、品牌、状态筛选与分页。
- 新建单规格 SPU 草稿，维护默认 SKU 的编码、条码、零售价、币种、重量与启用状态。
- 编辑单规格商品时保留已有普通参数、商品图片、SKU 图片及尺寸。
- 支持商品详情、上架、下架、归档；归档操作需确认且不可再次上架。
- 多规格商品本阶段仅提供详情与状态管理，销售属性组合编辑、品牌及属性模板维护留待后续阶段。
- 商品接口保留 `/api` 前缀，通过 Vite 代理访问已运行的 `8080` 后端。
- 默认 SKU 的规格签名为 `""`，后端 `ProductCmd.SkuCmd` 须允许空签名。部署本次后端改动后才能保存默认 SKU 覆盖字段。
