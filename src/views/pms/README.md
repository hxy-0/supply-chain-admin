# 商品管理

管理员菜单：商品管理 → 品牌管理、SPU管理、SKU管理、分类。菜单和管理员角色关联由 `db/postgresql/pms_menu_seed.sql` 幂等初始化。

- 品牌：筛选、分页、新增、编辑、启停、删除。已被商品引用的品牌不能删除。
- 分类：树形搜索、新增根分类/子分类、编辑、显示/隐藏、排序、删除。最多三级，不能形成循环；关联商品或属性模板的分类不能删除。
- SPU：筛选分页、详情、单规格/多规格草稿创建、基础资料编辑、上架/下架/归档。新增多规格可维护销售属性和值并生成最多 200 个组合。
- SKU：按商品/编码/条码查询，维护编码、条码、名称、价格、币种、重量、尺寸、状态。已有多规格 SPU 的规格身份保持不变，其价格和库存单位资料由 SKU 页面维护。
- 修改 SPU/SKU 使用版本号，拒绝覆盖他人更新；归档商品不能继续编辑或上架；上架商品须至少有一个启用 SKU，且所有启用 SKU 价格大于零。

接口保留 `/api` 前缀，通过 Vite 代理访问 `8080`。本地首页为 `http://127.0.0.1:8848/#/pms/brands`。

验证：`node --experimental-strip-types scripts/specifications.test.mjs`；前端 TypeScript/ESLint/Stylelint/生产构建；后端品牌、分类、SKU、命令校验单元测试。`python db/postgresql/test_pms.py` 使用本地配置运行真实 PostgreSQL 商品生命周期测试，全部写入通过事务回滚。
